# Dell Store

Вёрстка интернет-магазина **Dell Store** по макету Figma
([«Тестовое (Copy)»](https://www.figma.com/design/TpfcHdPrw3ynidfAwBhx8T/)).

Статический адаптивный сайт на чистом HTML, CSS и JavaScript — без сборщиков и
зависимостей. Открывается двойным кликом по `index.html`.

## Страницы

| Файл | Экран макета | Описание |
|------|--------------|----------|
| `index.html` | Главная | Hero, каталог категорий, преимущества, контакты с формой заявки |
| `catalog.html` | Каталог | 6 категорий товаров + блок доставки |
| `laptops.html` | Каталог Ноутбуки | Листинг с фильтрами (цена, диагональ), сортировкой и «Загрузить ещё» |
| `product.html` | Карточка товара | Галерея, покупка, вкладки характеристик, похожие товары |
| `login.html` | Вход | Форма входа (с демонстрацией ошибки авторизации) |
| `register.html` | Регистрация | Форма регистрации |
| `account.html` | Личный кабинет | Профиль и история заказов |

## Структура

```
├── index.html, catalog.html, laptops.html, product.html
├── login.html, register.html, account.html
└── assets/
    ├── css/style.css      — все стили и адаптив
    └── js/
        ├── components.js  — общие шапка и подвал (инжектятся на каждой странице)
        └── main.js        — корзина, тосты, фильтр цены, вкладки, формы, анимации
```

## Возможности

- Общие шапка/подвал через JS — работают даже при открытии по `file://`.
- Полностью адаптивная сетка (десктоп / планшет / мобильный) с бургер-меню.
- Интерактив: добавление в корзину со счётчиком и уведомлением, избранное,
  двойной ползунок цены, вкладки характеристик, выбор количества,
  «Загрузить ещё», валидация форм, анимация появления секций.
- Иконки и заглушки изображений — встроенный SVG, поэтому сайт самодостаточен и
  не тянет внешних файлов (кроме шрифта Roboto из Google Fonts).

## Примечание по изображениям

Фотографии товаров из макета размещены на серверах Figma и в текущем окружении
недоступны для загрузки, поэтому вместо них используются аккуратные
SVG-заглушки в фирменной палитре. Структура, тексты, типографика, цвета и
раскладка соответствуют макету — заглушки при необходимости легко заменить на
реальные фото.

## Запуск

```bash
# просто откройте index.html, либо поднимите локальный сервер:
python3 -m http.server 8000
# → http://localhost:8000
```
