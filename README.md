# Elfen lied

Вёрстка сайта магазина дизайнерского декора **Elfen lied** по макету Figma
([«Тестовое (Copy)»](https://www.figma.com/design/TpfcHdPrw3ynidfAwBhx8T/)).

Статический адаптивный лендинг на чистом HTML, CSS и JavaScript — без сборщиков и
зависимостей. Открывается двойным кликом по `index.html`.

## Секции страницы

- **Шапка** — логотип Elfen lied, меню (Каталог, Блог, Контакты), розовая строка
  поиска и голубой кластер иконок (избранное, профиль, корзина).
- **Hero «товар дня»** — водяной знак *Benjamin Moore*, товар Santa Trinita,
  цена и кнопка «Купить», плюс две панели стилей (розовая / голубая).
- **Категории** — напольные зеркала, торшеры и лампы, кресла и стулья, столы и тумбы.
- **Каталог** — фильтры (цена, цвета) и сетка товаров-зеркал (Kristin, Arlene,
  Colleen, Coppelia, Artemide), кнопка «Загрузить еще».
- **Лента** — бегущие строки *creating a great art* (marquee).
- **Блог** — карточки статей.
- **Подвал** — навигация, контакты, соцсети.
- **Всплывающие окна** (как в макете): быстрый просмотр товара (коллекция,
  артикул, цвет, высота, описание, «Купить») и выдвижная корзина с оформлением
  заказа (Ваше имя, Адрес, Телефон).

## Структура

```
├── index.html
└── assets/
    ├── css/style.css      — стили, палитра, анимации, адаптив
    └── js/
        ├── components.js  — общие шапка и подвал (инжектятся на странице)
        └── main.js        — корзина, поиск, фильтры, ползунок цены,
                             «Загрузить еще», тосты, анимация появления
```

## Возможности

- Фирменная палитра: лавандовый фон, розовые/голубые панели, лаймовый акцент,
  serif-типографика (Playfair Display) + Manrope для интерфейса.
- Интерактив: добавление в корзину со счётчиком, тумблер фильтров, двойной
  ползунок цены, выбор цветов, «Загрузить еще», поиск, всплывающие уведомления.
- Анимации: появление секций при скролле, бегущие ленты, ховер-эффекты.
- Полная адаптивность (десктоп / планшет / мобильный) с бургер-меню.

## Примечание по изображениям

3D-рендеры товаров из макета размещены на серверах Figma и в текущем окружении
недоступны для загрузки (заблокированы egress-политикой), а также был достигнут
лимит вызовов Figma MCP на тарифе Starter. Поэтому вместо конкретных 3D-объектов
используются стилизованные SVG-заглушки в фирменной палитре. Композиция, тексты,
цвета, типографика и анимации соответствуют макету — заглушки при необходимости
легко заменить реальными изображениями.

## Запуск

```bash
# откройте index.html, либо поднимите локальный сервер:
python3 -m http.server 8000   # → http://localhost:8000
```
