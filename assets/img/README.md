# Изображения из Figma

Сюда нужно положить картинки, экспортированные из макета Figma. Код подхватывает
их **автоматически по имени файла** — если файла нет, показывается
SVG-плейсхолдер, поэтому сайт не ломается на любом этапе.

## Как экспортировать из Figma

1. Открой макет: <https://www.figma.com/design/TpfcHdPrw3ynidfAwBhx8T/>
2. Выдели нужный объект (3D-модель товара / категории).
3. Панель справа → **Export** → формат **PNG** (для объектов — с прозрачным
   фоном), масштаб **2x** → **Export**.
4. Переименуй файл ровно как в таблице ниже и положи в эту папку `assets/img/`.
5. Закоммить и запушь — GitHub Pages обновится автоматически.

## Как это работает

- Объекты товаров/категорий выводятся как `background-size: contain` (объект
  целиком, лучше с прозрачным фоном).
- Картинки блога — как `background-size: cover` (заполняют карточку).
- Добавишь новый товар с именем `Название` — положи `product-название.png`
  (латиницей, в нижнем регистре), и он подхватится сам.

## Рекомендации

- **Формат:** PNG. Для 3D-объектов — с прозрачным фоном.
- **Размер:** ~600–1000 px по большей стороне (2x при экспорте), чтобы было
  чётко на Retina.
- Держи файлы лёгкими (сожми через TinyPNG), чтобы страница грузилась быстро.
