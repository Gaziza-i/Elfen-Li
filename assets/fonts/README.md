# Шрифты из макета

Макет использует два фирменных шрифта:

| Шрифт | Где | Файл (положи сюда) |
|-------|-----|--------------------|
| **Euclid Circular A** (Medium) | основной текст, заголовки, меню | `EuclidCircularA-Medium.otf` (или `.woff2`) |
| **Floreste, начертание Wavy** | числа: плашка «N мин», номера панелей, лента | `Floreste.otf` (или `.woff2`) |

Пока файлов нет, сайт использует бесплатные фолбэки: **Poppins** вместо Euclid
и **Playfair Display** вместо Floreste (подключаются автоматически).

## У тебя уже есть Floreste — как подключить

Если на компьютере лежит папка со шрифтом Floreste (`Floreste.otf`,
`FlоresteItalic.otf`, `FloresteOutline.otf`, `FloresteWavy.otf`, `COPYRIGHT`) —
**конвертировать не обязательно**. Браузеры отлично читают `.otf` напрямую.

1. Нужно только начертание **Wavy** (именно оно указано в макете для цифр).
2. Переименуй `FloresteWavy.otf` → **`Floreste.otf`**.
3. Положи файл в эту папку `assets/fonts/` (рядом с этим README).
4. Закоммить и запушь (на GitHub: **Add file → Upload files**) — `@font-face`
   в `assets/css/style.css` подхватит файл автоматически, конвертация и
   правка кода не нужны.

Остальные начертания (`Floreste.otf` обычный, `FloresteItalic`,
`FloresteOutline`) в макете не используются — их можно не загружать.

## Euclid Circular A

Аналогично: возьми файл шрифта (`.otf`, `.woff2` или `.ttf` — любой сработает),
назови `EuclidCircularA-Medium.otf` и положи сюда же.

## Технические детали

`@font-face` уже прописан в `assets/css/style.css` и пробует несколько
форматов по очереди (`woff2` → `woff` → `otf` → `ttf`) — какой файл найдёт,
тот и использует. Отсутствующие файлы просто пропускаются без ошибок, ничего
в коде менять не нужно, только положить сюда сами файлы шрифтов.

Если всё же захочешь сжать до `.woff2` (чуть быстрее грузится, файлы обычно
на 30–50% легче) — конвертер: <https://cloudconvert.com/otf-to-woff2>. Но это
опционально, `.otf` тоже работает без проблем.
