# Шрифты из макета

Макет использует два фирменных шрифта:

| Шрифт | Где | Файл (положи сюда) |
|-------|-----|--------------------|
| **Euclid Circular A** (Medium) | основной текст, заголовки, меню | `EuclidCircularA-Medium.woff2` (и `.woff`) |
| **Floreste** (Wavy) | числа: плашка «N мин», номера, лента | `Floreste.woff2` (и `.woff`) |

Оба шрифта **коммерческие** — в этом окружении их скачать нельзя. Пока файлов
нет, сайт использует бесплатные фолбэки: **Poppins** вместо Euclid и **Playfair
Display** вместо Floreste (подключаются автоматически).

## Как подключить настоящие шрифты

1. Получи файлы шрифтов (из проекта Figma / у дизайнера / купленную лицензию).
2. Переведи в `.woff2` (напр. на <https://cloudconvert.com/ttf-to-woff2>).
3. Назови ровно как в таблице выше и положи в эту папку `assets/fonts/`.
4. Закоммить и запушь — `@font-face` в `assets/css/style.css` подхватит их
   автоматически, и весь сайт станет 1:1 по типографике макета.

`@font-face` уже прописаны в `assets/css/style.css`, менять код не нужно —
только добавить файлы.
